## How to Use

### View the Website
Open `index.html` in your browser.

### Admin Dashboard
1. Open `admin.html` in your browser
2. Login with password: `admin123`
3. Manage your restaurant content:
   - **Dashboard**: View stats and recent reservations
   - **Infos Restaurant**: Edit name, phone, address, hours, Instagram
   - **Menu**: Add, edit, delete dishes
   - **Gallery**: Add, edit, delete photos
   - **Reviews**: Add, edit, delete customer reviews
   - **Reservations**: View all booking requests
   - **Settings**: Reset data, change admin password

### Add Your Photos
Place your photos in the `images/` folder with these names:
- `hero-bg.jpg` — Hero background image
- `about.jpg` — About section image
- `menu-brique.jpg` — Brique Fruits de Mer
- `menu-spaghetti.jpg` — Spaghetti Fruits de Mer
- `menu-plateau.jpg` — Plateau de Fruits de Mer
- `menu-poisson.jpg` — Poisson du Jour
- `menu-salade.jpg` — Salade Méditerranéenne
- `menu-vins.jpg` — Cave à Vins
- `gallery-1.jpg` through `gallery-8.jpg` — Gallery photos
